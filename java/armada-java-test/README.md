# Armada Java testing support

## Installation

### Maven
* Add the dependency using your dependency management tool.

```xml

<dependencies>
    <dependency>
        <groupId>io.armadakv</groupId>
        <artifactId>armada-java-test</artifactId>
        <version>VERSION</version>
        <scope>test</scope>
    </dependency>
</dependencies>
```

### Gradle

```kotlin
dependencies {
    testImplementation("io.armadakv:armada-java-test:VERSION")
}
```
